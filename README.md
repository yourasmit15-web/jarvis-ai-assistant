# jarvis-ai-assistant

Phase 1 implementation of JARVIS with:
- FastAPI backend (AI brain, orchestrator, tools, permissions, memory, audit)
- React dashboard (chat, status, permissions, memory viewer, activity log)
- Security-first permission and confirmation layers
- Docker + documentation + pytest coverage for core modules

See `/docs/SETUP.md` for local setup and `/docs/API.md` for endpoints.
